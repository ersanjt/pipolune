# Pipolune — правила работы с проектом

## Обязательное правило владельца

Любое исправление, добавление или переделка сначала выполняется в проекте GitHub `ersanjt/pipolune`. Только после фиксации и отправки соответствующего коммита в GitHub разрешено применять эту версию на сервере.

1. Перед началом прочитать актуальные инструкции и получить последние изменения из GitHub. Не перезаписывать чужую работу.
2. Внести изменения в исходники проекта. Для кода сайта выполнить предусмотренную сборку и необходимые проверки.
3. Создать коммит и отправить его в GitHub. Локальные изменения без отправки не считаются переданным результатом.
4. Только затем развёртывать именно отправленный коммит через существующий процесс доставки. В этом проекте push в `main` запускает GitHub Actions и автоматический деплой: не дублировать его ручной загрузкой.
5. Проверить результат соответствующего workflow/деплоя. Не утверждать, что сайт обновлён, пока успешное развёртывание не подтверждено.
6. Если GitHub недоступен или push не выполнен, на сервер ничего не применять; сообщить, что осталось незавершённым.
7. Изменения файлов проекта непосредственно на сервере без предварительного коммита и push запрещены. Пароли, ключи и конфигурация секретов хранятся отдельно и не коммитятся.

## Визуальные ориентиры

Использовать `docs/brand/approved-style-v1.1.ru.md`, `docs/uiux/uiux-foundation-v1.ru.md` и исходные `design/reference/00–06`. Для кабинета и трекинга — компоненты листа 04. Отклонённые перерисовки не считать утверждёнными. Не менять стиль и логотип без прямого указания владельца.

## Добавление товаров

Когда владелец присылает ссылку на товар (1688, Taobao, Tmall, AliExpress или другой магазин) или данные поставщика, работать строго по `.cursor/skills/add-product-from-link/SKILL.md`. Каждый товар получает полный стандартный набор: обложку, галерею фото, видео, тексты EN/TR/RU, подробное описание, характеристики, таблицу размеров, детали крупным планом, вес посылки, цены ₺/$/₽ (вручную, без пересчёта) и данные закупки, видимые только сотрудникам. Образец — товар `acorn-hooded-jumpsuit`. Медиа готовить скриптом `scripts/product-media.py`. Не публиковать отзывы поставщика и изображения с китайским текстом, логотипами или водяными знаками.

## Связанные инструкции

Читать `.cursor/rules/git-sync.mdc`. Никогда не включать в GitHub `private/`, настоящие `.env`, ключи SSH, пароли и персональные документы. Примеры конфигурации должны содержать только безопасные заглушки.

Правило зафиксировано по прямому запросу владельца 25 октября 2026 года.
